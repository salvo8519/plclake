# Changelog

All notable changes to this project are documented in this file following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic Versioning.

## [Unreleased]

Hardening release (issue #2). No new features.

### Security
- Production always enforces API authentication (`NODE_ENV=production`): `API_ENFORCE_AUTH=false` and the console "trusted-lan" toggle can no longer open admin routes to anonymous callers.
- No default passwords in the code base: built-in accounts read `AUTH_ADMIN_PASSWORD`, `AUTH_DEMO_OPERATOR_PASSWORD`, `AUTH_DEMO_VIEWER_PASSWORD`; outside production, missing ones are generated and written once to `.state/initial-credentials.txt` (0600). Demo operator/viewer accounts are seeded only with `AUTH_SEED_DEMO_USERS=true` and never in production. The login screen no longer ships prefilled credentials.
- Outbound SSRF policy now validates every DNS-resolved address (webhook, Mailpit, SMTP, PLC probes); TCP probes connect to the validated IP.
- Login hashing is asynchronous and constant-cost for unknown accounts (no event-loop blocking, no user enumeration by timing). Password changes revoke existing sessions; short passwords are rejected instead of silently ignored.
- Edge gateway never sends the HTTP meter bearer token over plain HTTP unless `EDGE_HTTP_METER_ALLOW_PLAINTEXT_TOKEN=true`.
- CI runs with `contents: read` permissions; actions upgraded to the Node 24 runtime.
- Outbound webhook, Mailpit, SMTP and HTTP meter probes connect only to the DNS addresses already approved by the SSRF policy (closes the DNS rebinding window); TLS still verifies the configured host name.
- Content-Security-Policy in production (strict `default-src 'none'` on API responses, `'self'`-based policy for the console) and HSTS over TLS. The Scalar API reference is excluded because it loads from a CDN.
- Unexpected handler failures return the handler's generic message; internal error details are logged with the request id instead of being sent to the client.
- HTTP REST meters have an explicit `useTls` flag (HTTPS on any port, e.g. 8443); legacy records keep the previous port-443 rule. The console locks the "trusted LAN" option when the server environment enforces authentication.

- Deployment stacks that run in production mode (root `docker-compose.yml`, on-prem Compose files and the bundle generated by the console) require `POSTGRES_PASSWORD` instead of shipping a weak default, publish internal services (PostgreSQL, Mailpit, Prometheus, Grafana, Garage) on `127.0.0.1` unless `PLCLAKE_BIND_ADDR` is set, and pin Mailpit to `v1.34.0`. The generated `edge-gateway.env` no longer carries database credentials the gateway never uses.

### Fixed
- Unhandled errors in async API handlers no longer crash the process: they return a generic JSON 500 (details logged server-side); malformed JSON returns 400.
- PostgreSQL configured but unreachable at boot: the app retries with backoff and then fails to start, instead of silently running on ephemeral local files. `/readyz` returns 503 while the database is unavailable.
- Continuous ingestion no longer grows memory and per-batch CPU without bound: aggregation windows are capped and evicted with exact cumulative counters.
- Readiness probes use `SELECT 1`; the feature row count uses the planner estimate on large tables instead of a full `COUNT(*)` on every probe and metrics scrape.
- Late events for aggregation windows already evicted from memory are counted in `lateEventsDropped` instead of re-creating the window and counting it twice.
- Deduplication keeps remembering recent events across its size limit (two-generation set instead of `clear()`).
- Edge spool: batches permanently rejected (HTTP 400/422) move to a dead-letter table instead of blocking all later telemetry; HTTP 413 splits the batch.

### Build and supply chain
- Biome lint is warning-free and CI fails on new warnings (`--error-on-warnings`); the configuration was migrated to the Biome 2.6 schema. React hook dependency warnings were false positives (filters that intentionally trigger a pagination reset, a run-once boot effect) and are documented in place.
- Reproducible builds: committed `package-lock.json` (npm is the only Node package manager; the unused `bun.lock` was removed). CI, GitLab CI and the Dockerfile use `npm ci`, with npm caching in GitHub Actions.
- Python dependencies pinned with hashes in `project_repo/machine-logs-ml-pipeline/src/requirements-lock.txt`; CI and the Python Dockerfile install with `--require-hashes`. `ruff` and `pip-audit` are pinned as dev dependencies.
- CI now runs every Python test file, including the simulator and dataset builder tests, plus a `pip-audit` vulnerability check.
- Renovate refreshes the npm lockfile weekly and tracks `pyproject.toml`.

### Changed (action required on upgrade)
- Production boot requires `AUTH_ADMIN_PASSWORD` (min 12 characters) and `SECRETS_ENCRYPTION_KEY`; the root `docker-compose.yml` now requires them and `GRAFANA_ADMIN_PASSWORD`.
- New `TRUST_PROXY` setting: set it when running behind an ingress so rate limits and audit logs see real client IPs.
- Tests read credentials from `vitest.config.ts`.

## [1.0.0] - 2026-11-22

### Added
- **Versioned OpenAPI 3.1 API (`/api/v1/*`) & Scalar Reference**:
  - Two-Tier Zod validation (`permissive` default with SHA-256 quarantine vs `X-Validation-Mode: strict`).
  - RFC 9745 / 8594 deprecation headers on legacy `/api/*` alias.
  - Multi-scope M2M authentication (`admin`, `read`, `edge`) verifiable via `/api/v1/auth/whoami`.
- **Parameterizable PLC Catalog & Edge Drivers**:
  - 8 built-in industrial profiles (Siemens S7-1500, Rockwell ControlLogix, CNC, Gas Metering, Power Generation) + custom PLC CRUD and output preview API.
  - Real Python OT Edge Collectors for Modbus TCP (pymodbus + zero-dep binary MBAP), OPC-UA, MQTT Sparkplug B, and HTTP REST meters with auto-sync config polling.
- **PostgreSQL Live Persistence & BI Connectors**:
  - Auto-bootstrapped `control_plane_state`, `ml_machine_features` (with forward-compatible `site_id`), `audit_log`, and `vw_ba_controllo_gestione_daily` SQL view.
  - Transparent atomic `.state/*.json` fallback for zero-dependency local execution.
  - Formula-safe RFC 4180 CSV & JSON endpoints for Power BI and Grafana.
- **Notifications, Alerting & SMTP Diagnostics (Mailpit + Webhook)**:
  - Dedicated **Notifications & Alerts** workspace supporting Email (SMTP / Mailpit via `nodemailer`) and HMAC-SHA256 signed HTTP Webhooks with SSRF protection.
  - Dedicated **SMTP Diagnostics** sub-section with embedded Mailpit Queue Depth & Connection Status card, SMTP handshake verification, custom diagnostic test email sender, and live Mailpit REST API inbox/message inspector.
- **RBAC Users & Immutable Audit Log**:
  - Dedicated **Users & Audit** workspace with `scrypt` password hashing, revocable `sess_...` sessions, optional OIDC proxy headers, and searchable/CSV-exportable Audit Log.
- **Platform Observability & Open-Source Packaging**:
  - Structured NDJSON logging (`src/logger.ts`) with deep recursive secret & token redaction.
  - Prometheus `/metrics` (and `/api/v1/metrics`), Kubernetes `/healthz` & `/readyz` probes, and `SIGTERM`/`SIGINT` graceful shutdown.
  - Two pre-provisioned Grafana dashboards (**Platform & System Observability** and **Plant & PLC Operations Monitoring**) and one-command root `docker-compose.yml`.
  - Zensical static documentation site with Mermaid architecture diagrams and automated GitHub Pages & CI workflows.
